# Pokemon 30th Brand MOD Draft

Pokemon 30th is an anniversary campaign style, not a RoCom-style torn-paper section chain.

Reusable visual language:

- responsive hero artwork with official PC/SP ratios
- 30th anniversary logo and monthly theme badge
- white rounded news cards with light shadow
- semantic category colors for News / Game / App / Card / Goods
- Japanese body typography from Noto Sans JP with Lato for English labels

Current boundary:

- This folder is a standard Brand MOD input draft.
- It is not applied to a business project.
- It is not yet a fully rendered standard demo page.
- Official Pokemon content assets are evidence for preview only; business projects should keep their own content unless the user asks otherwise.
