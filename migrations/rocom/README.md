# RoCom Golden Template

RoCom is the first golden template for a bright game/IP official-site style.

This migration starts from the existing demo draft in `src/App.vue` and `src/styles.css`. Its goal is not to copy official business content, but to preserve reusable design language for future `/brand` runs:

- yellow-black / black-gold page canvas
- warm parchment panels
- warm yellow primary CTA
- thick rounded controls
- light fantasy image layers
- home/news/media/pet/publish page structure

Use this folder as the evidence source before applying RoCom-like style to another business project.
